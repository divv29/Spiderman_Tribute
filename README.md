# 🕷️ Peter Parker | Spider-Man Tribute

**A responsive fan-made tribute website to Spider-Man in the MCU.**
Built with plain HTML, CSS and JavaScript. No frameworks, no build step.

## ✨ Features

- **Full-screen hero** with a gradient title and an Explore button
- **Sticky navigation bar** that changes style as you scroll
- **Smooth scrolling** between sections
- **About section** on Peter Parker
- **Key Moments in the MCU** timeline, from *Civil War* (2016) to *No Way Home* (2021)
- **Image gallery** with six photos
- **Iconic Quotes slider** with dots, arrows and auto-advance every 5 seconds
- **Spider-Man colour palette** (red, blue and gold) using CSS variables

## 🚀 Run it locally

No installation needed. Download or clone the repo and open `index.html` in your browser.

```bash
git clone https://github.com/divv29/Spiderman_Tribute.git
cd Spiderman_Tribute
open index.html        # macOS
```

## 🗂 Project structure

```
Spiderman_Tribute/
├── index.html      # page structure, styles and scripts
├── images/         # hero, about and gallery images
└── README.md
```

## 🎨 Customising

Colours are CSS variables at the top of the `<style>` block in `index.html`:

```css
:root {
    --spider-red: #e62429;
    --spider-blue: #235789;
    --spider-accent: #f9cb40;
}
```

To change the photos, replace the files in `images/` and keep the same file names.
